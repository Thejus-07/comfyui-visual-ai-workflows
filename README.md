# comfyui-visual-ai-workflows

Portable ComfyUI workflows and documentation for running local generative AI pipelines (text→image). This repository packages concise Quick Start instructions, a reusable Text→Image workflow guide, and an example workflow screenshot — suitable to include in a portfolio or resume.

Resume blurb
- Built a portable, documented toolkit that packages ComfyUI workflows and setup instructions for reproducible local generative-AI pipelines. Includes step-by-step Quick Start, workflow blueprint guidance, and a sample workflow for easy demonstration.

Highlights
- Quick start instructions for Windows portable builds: `README_QUICK_START.md`
- Step-by-step Text→Image workflow guide: `WORKFLOW_TXT2IMG.md`
- Example workflow screenshot: `assets/workflow_screenshot.jpeg`
- Excludes large models and embedded Python runtime via `.gitignore` to keep repository size small.
